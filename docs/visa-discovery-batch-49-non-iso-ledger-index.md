## Reconciliation rules

1. Do not assign an invented ISO-2 or ISO-3 code to any non-ISO child destination.
2. Do not create country-master rows or separate country-level visa requirements for these candidates until an approved parent-child model exists.
3. Country-level visa rules remain attached to the parent country or jurisdiction. Child entry, transit, regional-permit and local-access rules require an explicit schema decision and must not overwrite the parent's visa record.
4. Keep entry, transit, regional permit, government fee, VAC fee, processing estimate, photo and checklist fields separate.
5. A candidate can move to production only after Bangladesh ordinary-passport applicability and all material route conditions are supported by current authoritative sources, the child-destination schema is approved, and the normal backup/restore/dry-run/readback gates pass.
6. On each run, compare this sidecar with the ISO country master and mark a candidate as represented only when its parent/child relationship is explicit. Do not count a sub-destination as a new sovereign country.

This sidecar currently contains **8 research-only candidates**: Northern Cyprus, Xizang/Tibet, Palmyra Atoll, Svalbard, Jan Mayen, Somaliland, Puntland and Mount Athos. None are counted as additional sovereign countries or as separate entries in the public directory. Svalbard and Jan Mayen remain represented by the existing composite ISO `SJ` master row until a parent-child model is approved.
